# Источники дополнительных фотографий

Девять иллюстраций внешнего вида растений из Wikimedia Commons. Это не фотографии экземпляров питомника; цвет, сорт и состояние посадочного материала по ним не определяются. Авторские снимки из архива питомника сохранены отдельно без изменений.

Все перечисленные копии уменьшены и преобразованы в WebP. При отображении карточка может обрезать края фотографии через CSS; содержимое снимков не ретушировалось. Каждая копия распространяется по указанной для неё лицензии оригинала.
