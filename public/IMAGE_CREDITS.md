# Фотографии растений

Фотографии показывают внешний вид растений. Изображения из открытых источников служат иллюстрациями вида и не являются фотографиями конкретного посадочного материала питомника.

Авторские снимки Геннадия Павловича Анисимова взяты из [фотоархива питомника](https://sem-ot-anis.narod.ru/index/0-73). Доступные авторские фотографии использованы в первую очередь. Для остальных растений сохранены локальные копии фотографий из Wikimedia Commons и iNaturalist с указанием автора и лицензии.

Новые копии уменьшены до 960 пикселей по большей стороне и преобразованы в WebP. Содержание снимков не ретушировалось. Для карточек фотографии могут обрезаться средствами CSS. Каждая фотография распространяется по собственной лицензии оригинала, указанной ниже.
