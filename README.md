# Питомник Анисимова

Сайт питомника редких растений Геннадия Павловича Анисимова в Томске. Каталог, цены и условия заказа перенесены из предоставленного владельцем документа **«Каталог 2027.docx»**, сезон **2026–2027**. Каталог действует до **15 октября 2027 года**.

Сайт публикуется в GitHub Pages: https://nst0v.github.io/pitomnik-anisimova-demo/. Имя существующего репозитория сохранено, чтобы не менять адрес публикации.

## Каталог и заказ

- Все 212 продаваемых позиций нового каталога: однолетники, многолетники, лекарственные, пряные и овощные растения, саженцы, корни, луковицы и печатный каталог следующего сезона.
- Поиск по названию, латинскому названию и каталожному номеру, категории и сортировка.
- Подробные описания, единицы продажи, минимальные количества и цены за объём.
- Локально сохранённые фотографии растений с источниками и авторством.
- Оригинал Word доступен для скачивания: [`public/catalog-2027.docx`](public/catalog-2027.docx).
- Составление заказа с количеством, Ф.И.О., контактом, адресом, способом доставки, кодом постоянного заказчика и сведениями об оплате.
- Сохранение заказа в браузере, расчёт стоимости с учётом объёмных цен, скидки и доставки.
- Копирование и скачивание готового текста заказа, открытие письма на **sem-ot-anis@mail.ru**.

Кнопка «Открыть письмо» запускает почтовое приложение. Посетитель проверяет и отправляет письмо самостоятельно. Если приложение не настроено или письмо слишком длинное, заказ можно скопировать и отправить через любую почту. Сайт не подтверждает отправку и получение заказа автоматически. Серверной формы и подключения к платёжной системе нет.

Черновики прежнего сезона не переносятся автоматически: номера нового каталога отличаются. Текущий ключ хранения — `anisimov-nursery-request-2027-v1`.

## Статьи о растениях

Раздел [«Статьи»](https://nst0v.github.io/pitomnik-anisimova-demo/#/articles) содержит 41 статью Геннадия Павловича Анисимова из [каталога статей старого сайта](https://sem-ot-anis.narod.ru/publ/). Для пяти материалов источниками служат предоставленные владельцем Word-файлы:

- «Загадочная альфредия»;
- «Безвременник»;
- «Кандык сибирский — самый ранний цветок»;
- «Купальница азиатская»;
- «Сибирская черемша».

В разделе есть поиск и тематические фильтры. Каждая статья опубликована один раз: повторные карточки и отдельные исторические версии не создаются. Для пяти перечисленных материалов используются загруженные владельцем файлы; они сохранены побайтово без изменений. На сайте доступны 41 текст для чтения и 41 Word-оригинал.

Каждая статья открывается по собственной ссылке вида `#/articles/<slug>`; такая ссылка работает после перезагрузки на GitHub Pages. Статьи связаны с соответствующими растениями каталога. Оригинальный Word можно скачать со страницы материала.

Авторские тексты и структура абзацев сохраняются. Старые рекламные окончания с прежними ценами и контактами отделены от текста для чтения; в скачиваемых оригиналах они остаются полностью. Материалы не выдаются за новые публикации и сохраняют ссылки на первоисточник и авторство. Из 43 записей старого раздела две служебные страницы («К читателям» и таблица прямых ссылок) отделены от 41 статьи и не увеличивают число материалов для чтения.

## Условия из каталога 2026–2027

Почта России: семена — **390 ₽**, посадочный материал — **550 ₽** за отправление. OZON, Яндекс Доставка и «Пятёрочка» (5 Post): семена — **230 ₽**, посадочный материал — **390 ₽**. Семена и посадочный материал отправляются раздельно; смешанный заказ включает стоимость двух отправлений. Печатный каталог № 212 за **60 ₽** высылается в конверте питомника в ноябре 2027 года и отдельного тарифа доставки не добавляет.

Заказы через Почту России оплачиваются полностью либо авансом: стоимость пересылки и не менее **30% стоимости товара**. Остаток оплачивается наложенным платежом; в этом случае почтовые расходы могут быть выше. OZON, Яндекс Доставка, 5 Post и отправления за пределы России требуют полной предоплаты. Международную доставку предварительно согласовывают и рассчитывают отдельно; калькулятор сайта показывает тарифы по России.

Скидка **10%** предусмотрена постоянным заказчикам и заказам **свыше 8 000 ₽**. При вводе кода постоянного заказчика сайт показывает предварительный расчёт скидки; действительность кода подтверждает питомник. Скидки не суммируются. Цены за объём применяются к количеству конкретной позиции.

Семена высылаются в течение **3–5 дней после получения аванса**. Сроки рассылки саженцев, луковиц и корней указаны в карточках. Заказы без оплаты или аванса не выполняются.

Оплата — на карту Сбербанка, привязанную к **+7 913 851-81-03**, получатель **Геннадий Павлович А.**, либо почтовым переводом **Анисимову Геннадию Павловичу, 634034, Россия, г. Томск, а/я 343**. Полные условия и контакты опубликованы на сайте из оригинального документа.

## Разработка

Требуются Node.js 22.18+ и npm; сборка в GitHub Actions использует Node.js 24.

```bash
npm ci
npm run dev
```

Проверки и сборка:

```bash
npm run typecheck
npm run test:audit
npm run test:e2e
npm run build
```

Браузерные проверки используют Playwright и Google Chrome. Они проверяют мобильные и настольные размеры, поиск и фильтры, карточки, количество и объёмные цены, сохранение заказа, копирование, текст письма и скачивание оригинального Word. Проверки статей дополнительно проверяют поиск и фильтры материалов, прямые ссылки после перезагрузки, чтение на экранах 360/390 px, переходы к каталогу и побайтовое соответствие пяти скачиваемых Word-файлов оригиналам.

## Структура

- [`src/data/catalog-2027.json`](src/data/catalog-2027.json) — 212 позиций из Word; [`scripts/import_catalog.py`](scripts/import_catalog.py) — повторяемый импорт с проверкой номеров, цен и минимальных партий.
- [`src/data/plants.ts`](src/data/plants.ts) — типы, категории и товары; оригинальные номера сохранены, записи со ссылками на другие позиции не дублируются как отдельные товары.
- [`src/data/articles.ts`](src/data/articles.ts) — типы и индекс материалов раздела «Статьи»; тексты из предоставленных владельцем файлов находятся в [`src/data/new-articles.json`](src/data/new-articles.json), исходные данные архива — в [`src/data/archive-articles.json`](src/data/archive-articles.json).
- [`scripts/prepare_articles.mjs`](scripts/prepare_articles.mjs) — объединение источников без дубликатов и подготовка индекса и текстов страниц; выполняется перед `npm run dev` и `npm run build`.
- [`scripts/import_new_articles.py`](scripts/import_new_articles.py) и [`scripts/import_archive_articles.py`](scripts/import_archive_articles.py) — повторяемый импорт исходных Word-статей; для повторного извлечения текстов нужен `antiword`, для обычной сборки он не требуется.
- [`public/articles`](public/articles) — тексты для чтения, оригинальные Word-файлы и изображения статей.
- [`src/lib/request.ts`](src/lib/request.ts) — объёмные цены, сумма заказа, скидка, доставка и текст письма.
- [`src/App.tsx`](src/App.tsx) — интерфейс каталога и заказа.
- [`src/styles.css`](src/styles.css) — адаптивное оформление.
- [`public/images`](public/images) и [`public/IMAGE_CREDITS.md`](public/IMAGE_CREDITS.md) — локальные изображения и источники.
- [`Каталог 2027.docx`](<Каталог 2027.docx>) — исходный документ владельца.

Фотографии из архива питомника используются в первую очередь. Дополнительные фотографии из открытых источников показывают внешний вид вида, а не конкретный экземпляр питомника; авторство и лицензии сохранены. Фотографии семян заменяются фотографиями самого растения.

Справочные материалы и история питомника: [старый сайт](https://sem-ot-anis.narod.ru/), [о питомнике](https://sem-ot-anis.narod.ru/index/0-59), [архив фотографий](https://sem-ot-anis.narod.ru/index/0-73). Источником текущих цен и правил заказа является предоставленный Word, а не прежние страницы старого каталога.

## Публикация

При отправке изменений в `main` workflow GitHub Actions проверяет каталог и расчёты, собирает `dist` и публикует его в GitHub Pages. Для другого адреса размещения проверьте настройку `base` в `vite.config.ts`.
